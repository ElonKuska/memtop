# MemTop

Живой топ процессов по памяти. Нужен root.

Маленькое приложение для себя: открыл — и сразу видно, кто жрёт память прямо сейчас. Список обновляется сам каждые пару секунд, умершие процессы плавно исчезают, новые — появляются.

## Что умеет

- топ-30 процессов по памяти (PSS, с fallback на RSS)
- живое обновление: появление / исчезновение / перестановка строк
- общая память с полоской (обновляется каждые 2 сек)
- 9 палитр x светлая / тёмная / как в системе: Espresso, Indigo, Forest, Sakura, Ocean, Sunset, Grape, Mono, Lime
- сочные анимации, пилюля-навбар с плавным индикатором
- русский интерфейс

## Требования

- Android 7.0+ (API 24)
- root (Magisk / KernelSU / APatch — любой, лишь бы `su` работал)

Без рута покажет «Нужен root» — так и задумано, без рута чужой PSS не снять.

## Сборка (без Gradle)

Всё собирается голыми `aapt2` + `d8`, скриптом:

```bash
bash build.sh
```

Нужны:
- `~/android-tools/build-tools/aapt2`, `zipalign`
- `~/android-tools/android-34/android.jar`
- `~/android-tools/r8lib.jar` (для d8)
- `~/android-ndk-r29` (для нативного `libmemtop.so`)
- JDK 17+

На выходе — `md3-empty.apk` (~320К), подписан дебажным ключом.

## Структура

- `src/com/example/md3empty/MainActivity.java` — экраны, живой дифф списка
- `RootProc.java` — скан через один вызов `su`: `ps` + `smaps_rollup`
- `ThemeManager.java` — 9 палитр, светлая/тёмная
- `ProcNative.java` + `jni/meminfo.cpp` — чтение `/proc/meminfo` через натив
- `res/` — темы, карточки 28dp, анимации
